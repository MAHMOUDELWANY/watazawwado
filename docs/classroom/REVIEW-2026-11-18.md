# Classroom deep review, 2026-11-18

This was a read-only logic and architecture review of Release 1. Each finding has a status that is updated as it gets
fixed. The "Fix owner" column names which part of the code the fix lives in:
- **engine:** the media engine and board files (`src/classroom/engine/*`, `board/Board.tsx`, `parts/Pointer.tsx`,
  `src/lib/lessonRoom.ts`).
- **page:** `src/classroom/ClassroomPage.tsx`. These fixes wait until the redesign of that file is done.
- **server:** the server routes (`server/routes/classroom.ts`). These fixes wait until the presence fix lands.

Only a real two-device browser test can confirm these:

- background tabs on mobile;
- laptop sleep;
- switching between Wi-Fi and mobile data;
- unplugging Bluetooth or USB devices;
- revoking permissions mid-lesson;
- `setSinkId` on Safari and Firefox;
- reusing mids;
