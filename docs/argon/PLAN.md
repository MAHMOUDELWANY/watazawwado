## Review sections (compressed)

1. **Architecture.** Two agents, one repo, one production branch. Coordination is through files (backlog status, log),
   enforcement through git (pre-commit hook), review through branches. No shared runtime state.
2. **Error & rescue map.**

| Failure | Trigger | Handler | What the owner sees |
|---|---|---|---|
| Agent edits an applied migration | Prompt drift | pre-commit blocks the commit | Agent logs "blocked" |
| Agent commits a secret | Copying env values | pre-commit blocks `.env*` files; rules forbid pasting keys | Nothing leaks via files; pasted strings are not caught (gap) |
| Broken build on `main` | Agent skips checks | Vercel keeps the previous deployment live on a failed build; rule says never leave `main` broken | Old site stays up |
| Passing build but wrong behaviour live | Weak tests | Red zone for money/booking/auth; OPS-01 error capture | Errors list on the admin page |
| Two agents take the same task | Race | Status commit first, `git pull --rebase` | Second agent sees "taken" |
| Agent changes curriculum | Ignores rule | Rules in three places; Claude checks the log and git history Friday | Claude reverts |
| Destructive SQL in production | Agent has Supabase access | Rule only (no technical guard) | Data loss: **highest residual risk** |

3. **Security.** Residual risks: Antigravity's Supabase connection can run any SQL (rule-only guard); secrets pasted
   into code are not detected by the hook. Mitigation for Claude on Friday: review migration history and
   `git log -p` for keys.
4. **Data flow / edge cases.** Covered per task (empty learner, foreign child 403, idempotent emails, Brevo daily limit).
5. **Code quality.** `api/index.ts` stays shared and large: agents keep edits local and prefer `server/routes/*`.
6. **Tests.** Every task requires `tsc`, `npm test`, build; QA-01 adds local end-to-end tests of money paths.
7. **Performance.** PU-04 measures before and after.
8. **Observability.** OPS-01..03 add error capture, health page, uptime and cron heartbeat.
9. **Deployment.** Push to `main` = production; rollback is the previous Vercel deployment (STATUS.md).
10. **Long term.** The contract (`AGENTS.md`) and hook keep working after Friday for any future agent.
11. **Design.** Progress experience principles written once at the top of the backlog (weekly rhythm, no leaderboards,
    real data, adab).
