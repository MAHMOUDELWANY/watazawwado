# دليل تجربة الـ 62 مهمة (للمالك)

الملف ده مكتوب بالعربي عشان إنت اللي هتستخدمه. كل مهمة فيها 4 أجزاء:

1. **اسم المهمة**
2. **بتعمل إيه**: الكلام هنا ببساطة ومن غير كلام برمجة.
3. **تجربها إزاي**: الخطوات اللي تعملها بنفسك على الموقع الحقيقي.
4. **تقريرك**: علّم على "شغال" أو "محتاج تعديل"، واكتب ملاحظتك.

**إزاي تملا التقرير:** حط `x` جوه القوس اللي يناسبك، كده: `[x]`. ولو أسهل عليك، ابعتلي في الشات رقم المهمة وكلمة "شغال" أو "محتاج تعديل" مع الملاحظة، وأنا هسجّلها هنا.

**حسابات التجربة:** محتاج تجرب بـ 3 أنواع حسابات عشان تشوف كل حاجة:
- **حساب ولي أمر**: إيميل تاني ليك، وضيف عليه طفل أو اتنين.
- **حساب مدرس**.
- **حساب الأدمن**: الحساب بتاعك.

حاجات كتير هتظهر بس بعد ما يحصل شيء حقيقي، زي حصة تخلص أو باقة تخلص. وده مكتوب عند كل مهمة.

### RN-02 تنبيه لما الباقة تقرّب تخلص
