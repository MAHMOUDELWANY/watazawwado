# Teacher University: Teaching Craft course (DRAFT)

Status: content draft v1, 2026-11-17. Needs owner and lead-teacher review before anything goes live (RULES.md: curriculum content waits for review).

## What this is

The teaching-craft layer of Watazawwado University (`/dashboard/university`, `src/dashboard/pages/UniversityPage.tsx`).
That page already handles the licence track per subject: study the curriculum, study the **teacher guide**, pass a test, pass an observed lesson.
This folder is the written content for the **teacher guide** step: how to plan, explain, check, correct, revise and keep growing, applied to each of our subjects.

It was built from a study of a language-teaching course for tutors (12 units) plus five handouts and an Oxford University Press position paper on professional development.
We took the ideas and rebuilt them in our own words, structure and examples. Nothing is copied. See [SOURCES.md](SOURCES.md) (internal, never published).

## Every module has the same shape

1. **Why it matters** (a hook question, 1 minute)
2. **The ideas** (short, one idea per block)
3. **In our lessons** (what changes for each subject)
4. **Try it** (one small task the teacher does in a real lesson)
5. **Check yourself** (3 to 5 original questions, with answers)
6. **Reflect** (one question for the discussion space)

Target length: 8 to 12 minutes per module. Short blocks, a task in every one, no wall of text.
