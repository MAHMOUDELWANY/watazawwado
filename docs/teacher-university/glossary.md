# Glossary: key terms (EN with Arabic gloss)

Our own wording. The Arabic gloss is to be reviewed when the mixed-language version is written.

| Term | Plain meaning | Arabic gloss |
|---|---|---|
| Learner-centred | Lessons where the learner does most of the work | تعليم متمحور حول المتعلم |
| Facilitator | A guide with expertise, not only a source of answers | ميسّر |
| Teacher talking time (TTT, not the framework) / Student talking time (STT) | How much each side speaks | زمن كلام المعلم / زمن كلام الطالب |
| Needs analysis | Finding out why, what and how the learner wants to learn | تحليل الاحتياجات |
| CEFR | Common scale of language levels A1 to C2 | الإطار الأوروبي المرجعي للغات |
| Lesson objective | What the learner can do at the end | هدف الدرس |
| Anticipated difficulties | Problems you predict before the lesson | الصعوبات المتوقعة |
| Personalisation | Linking a task to the learner's own life | التخصيص |
| PPP | Present, practise, produce | العرض والتدريب والإنتاج |
| TTT (framework) | Test, teach, test | الاختبار ثم التعليم ثم الاختبار |
| TBLT | Task-based language teaching | التعليم القائم على المهام |
| Text-based presentation | Target language is taken from a text | العرض القائم على نص |
| Flipped lesson | Learner prepares first; lesson time is for practice | الفصل المقلوب |
| Lead-in | The first minutes that open the topic | التمهيد |
| Eliciting | Drawing answers out of the learner | الاستنباط (الاستخراج بالأسئلة) |
| CCQ | Concept-checking question | سؤال فحص الفهم |
| MFP | Meaning, form, pronunciation | المعنى والصيغة والنطق |
| Appropriacy | Fit with situation and formality | ملاءمة الأسلوب للموقف |
| Target language | The item the lesson focuses on | اللغة المستهدفة |
| Context | The situation or text in which language appears | السياق |
| Controlled practice | Tasks with limited correct answers | تدريب موجَّه |
| Freer practice | Open tasks where the learner chooses the words | تدريب حر |
| Deductive / inductive | Rule first / examples first | استنباطي (من القاعدة) / استقرائي (من الأمثلة) |
| Guided discovery | Learner finds the rule from examples with help | الاكتشاف الموجَّه |
| Metalanguage | Technical words for describing language | لغة واصفة (مصطلحات) |
| Receptive skills | Reading and listening | المهارات الاستقبالية |
| Productive skills | Speaking and writing | المهارات الإنتاجية |
| Skimming / scanning / detail reading | Main idea / one fact / careful reading | قراءة سريعة للفكرة / للبحث عن معلومة / تفصيلية |
| Gist | The general idea | الفكرة العامة |
| Authentic materials | Material made for native speakers | مواد أصيلة |
| Pre-teaching | Teaching a few words before a text | التمهيد بالمفردات |
| Genre | A type of text with its own form | النوع النصي |
| Product / process writing | Model-then-write / plan-draft-revise | الكتابة بالنموذج / الكتابة بالمراحل |
| Error / slip | Does not know / knows but slipped | خطأ معرفي / زلّة |
| Fossilised error | An error that has become habit | خطأ متحجِّر |
| On-the-spot / delayed correction | Now / after they finish | تصحيح فوري / مؤجَّل |
| Recast | Saying it back correctly without calling it wrong | إعادة الصياغة الصحيحة |
| Self-correction | The learner fixes it themselves | التصحيح الذاتي |
| Phoneme | The smallest unit of sound that changes meaning | وحدة صوتية |
| Word stress / sentence stress | Stronger syllable / stronger words | نبر الكلمة / نبر الجملة |
| Intonation | The melody of speech | التنغيم |
| Drilling | Repeating to build habit | التكرار التدريبي |
| Chunk | A group of words that go together | وحدة لغوية (تركيب جاهز) |
| Collocation | Words that usually go together | المصاحبة اللفظية |
| Spaced repetition | Revisiting at growing gaps | التكرار المتباعد |
| Deep processing | Working with meaning, not just memorising | المعالجة العميقة |
| Recycling | Bringing language back in new contexts | إعادة التوظيف |
| First language (L1) / false friend | Learner's mother tongue / look-alike word with a different meaning | اللغة الأولى / صديق كاذب |
| Principled eclecticism | Choosing among methods on purpose | الانتقائية المنهجية |
| Rapport | The relationship between teacher and learner | العلاقة والألفة |
| Self-directed PD | Development you choose and steer | التطوير المهني الذاتي |
| SWOT | Strengths, weaknesses, opportunities, threats | تحليل القوة والضعف والفرص والتهديدات |
| Reflective practice | Learning by thinking about your own practice | الممارسة التأملية |
