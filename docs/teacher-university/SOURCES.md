# Sources (internal, never published)

Rules we followed: ideas and research findings are not copyrighted; the wording, examples, structure and design are. So we rebuilt every module in our own words, with our own examples, subjects and order. No text, template wording or example scenario was copied. Where the source cites a named author's idea (for example the deductive/inductive distinction, the "efficient and appropriate" filters, the four moves for emergent language), we keep the idea and, if we ever publish a reading list, we credit the original author.
