# Tajweed · binding rules (all levels)

Design: `docs/superpowers/specs/2026-10-25-subjects-curricula-design.md` §4.4. `docs/curriculum/RULES.md` wins on conflict.

1. **Learners already read the Mushaf** (Literacy A → Literacy B → Quran Reading). Tajweed teaches how to recite it.
2. **Three levels:** Level 1 the essential rules applied while reciting; Level 2 makharij and sifat; Level 3 advanced rules.
3. **Scope only from books:** Jannat al-Quran *Tajweed* Books 1, 2, 4 (Book 3 missing) for the order, checked against
   *Taysir ar-Rahman fi Tajweed al-Quran*. Never their wording, tables or exercises. Rules follow the narration of Hafs
   from Asim by way of ash-Shatibiyyah, as in the Mushaf of the King Fahd Complex.
4. **Quran text from Tanzil (Uthmani Hafs) only,** fetched, never typed from memory. Ayat play the reciter (Husary,
   muallim) on tap; a clone never recites the Quran. A clone may say Arabic that is not Quran (a word, the isti'adha).
5. **The lesson shape:** a rule is a colour layer on a real ayah that switches on; the reciter plays the ayah; the
   learner hears the rule before naming it; then practice on new ayat, then the learner recites to the teacher.
6. **One rule per lesson,** with its name in Arabic and a plain English name. Rule names are introduced once, then used.
7. **Evidence:** every ayah and hadith verified (Tanzil via the Quran connector, Dorar for hadith) and logged in the
   lesson brief. Every ayah shown as evidence has a tadabbur stop.
8. **Versions:** one shared version for 12+ first (Adults stage); a Kids version later in the Kids look.
