Generated by `npx tsx scripts/curriculum/clips.ts --by-voice` (owner, 2026-11-03). Each voice is one numbered list:
a line used in several lessons is recorded once. Paste each part as one ElevenLabs generation, in order, and send
the files named `<voice>-part-<n>.mp3`. Claude cuts each take on the silences, in this order, using `by-voice.json`
(the frozen order), and copies every line to all the files it serves. Quran ayat are never recorded (the reciter
streams them). The "owner" list is recorded by the owner himself, one take, same idea.
