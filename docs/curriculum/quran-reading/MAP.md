# Quran Reading (no tajweed) · 12+ · MAP

Design §4.3: reading fluency from the Mushaf, after Literacy A and B. Mostly practice: each lesson is a graded passage
read in three moves (listen to the reciter, follow the line, read it yourself), one reading focus per passage taken from
Literacy B (small alif, hamzat al-wasl, shadda, madd sign, stopping), and the teacher marks each ayah (smooth, paused,
helped). Short surahs first, then longer passages. Text: Tanzil Uthmani Hafs; audio: Husary (muallim).

Status: Claude's draft, 2026-10-26, for the owner's review.
