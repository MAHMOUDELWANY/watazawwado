# Literacy A · Reading Arabic · Teens (12–17) · MAP

Same scope and order as the Kids and Adults maps, told as cracking a code: every lesson unlocks letters, and from
Lesson 9 the learner decodes real messages (a friend's chat, a shop sign, a game screen in Arabic). Two letter families
per lesson after Lesson 1, as for Adults. No religious content (design §4.1). Status: Claude's draft, 2026-10-26.
