# Literacy A · Reading Arabic · Kids (6–11) · MAP

Design: `docs/superpowers/specs/2026-10-25-subjects-curricula-design.md` §4.1. For Muslims and non-Muslims: no religious
content anywhere (our own neutral words and cast). Order from the literacy sources (Jannat al-Quran *Arabic & Tajweed*
Book 1, *Nour al-Bayan*, *Fath ar-Rahman*, *Steps for writing the letters*; sources.md §H): letters → positions and
joining → short vowels → sukoon, shadda, tanween → long vowels → reading. Letters grouped by shared body, so each lesson
has one "aha" (the dots or one small change make a new letter). Teens and Adults versions follow the same order with
their own look and pace.

Status: Claude's draft map, 2026-10-25, for the owner's review.
