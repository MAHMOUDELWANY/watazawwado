# Watazawwado promo video

Remotion project. `npm install`, then:

- `npm run studio` to preview and edit
- `npx remotion render src/index.ts PromoSfx out/watazawwado-promo-sfx.mp4` (sound effects, no photo)


Voice-over: `public/vo-full.mp3` (owner's ElevenLabs take, loudness-normalised); sentence times in `src/captions.tsx`. Scene timing is in `S` at the top of `src/Promo.tsx`.
